This is meant to help you on your Hiragana journey. Simply extract the contents of the .rar file into a folder, and make sure all the small sound files are in the same folder as the main HTML file, since that’s the main way of “entering” the program. It’s basically a simple website that you can run offline.

Press any hiragana character and it will appear in the text area, which is ideal for quickly copying and pasting. It will also play the sound respective to the hiragana.

You can also translate to romaji by pressing the ABC button.

Finally, if you press the speaker icon, it will read aloud whatever hiragana you’ve pasted. Note that it does not merge sounds correctly for combinations, so treat it as reading syllable by syllable rather than natural pronunciation.
